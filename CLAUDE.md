# CLAUDE.md — project rules for coding agents

> Read this file at the start of every session. It overrides any session-level defaults.

## Session start
After docs/PLAN.md, read docs/additions.md (the additions register). Check every Pending or
Planned entry's Constraints against what the session is about to build, so the new code does not
have to be reworked when that addition lands. When the team suggests something new, append it
there as the next A-NNN straight away.

## Commit style
Do not add Co-Authored-By lines to commit messages.
